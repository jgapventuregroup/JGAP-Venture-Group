What the machine does

The product is not another property-listing website. The value is filtering, change detection and investor-specific alerts.

1. Watch

Monitor approved data and listing sources for new opportunities and material changes.

2. Filter

Apply the subscriber's geography, property type, unit count, price and return criteria.

3. Score

Rank matches and clearly separate verified numbers from estimates and missing information.

4. Alert

Send only meaningful matches instead of forcing an investor to search through hundreds of listings.

5. Track

Keep a history of price changes, first-seen dates and previously reviewed opportunities.

6. Improve

Use feedback and real outcomes to improve the matching model over time.

Built around the investor's buying box

A subscriber could specify something like:

East Tennessee + Southwest Virginia • 2–20 units • 8%+ cap when available • 1.20+ DSCR when available • $500+ monthly cash flow when available • flag price reductions automatically.
